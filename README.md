# Announcement

Where did Solébot go? It has gone to [Codberg.org](https://codeberg.org/crunchysteve/SoleBot), as have most of my other repos, although a few have been deleted.

Why? After experiementing with the hyperscale AIs and finding them pretty much useless, then, seeing a very dear friend let his brains fall out by using AI how he should do anything in his life, all the while admitting his own laziness. The enshittification brought about by AI doing the work of humans or humans using AI to do work they're not qualified to do, I'm cutting AI out of my life in the ways I have control over and, where it might be useful, only running small, local hosted models on hardware I own and can isolate.

Part of this was turning off CoPilot here, only to find that, while it's tuned of when I'm coding, CoPilot still intrudes at my commit info. Of all the things I've never needed AI for, commits are one of them. I'm a hobbyist, not a professional. I'm a socialist, not a capitalist. My commit info is for me and none of it needs tracking and I Never needed a CoPilot co-writer for the commits I was making, and mostly don't need a traceable workflow. Arduino code is pretty simple stuff.

For me, Github was, before Microsoft bought it, a place to store my code that had a cool history. Using Github felt like beng distantly associate with Linus.

Since Microsoft took over, wheedling CoPilot insistently into my face, more annoying than Clippy ever was, finally refusing to allow me to even write my commits in peace, even though I turned it off everywhere I was allowed to - Time to quit Github. One repo at a time, staring with Solebot, because it's the most important coding project in my small existence.

When the AI comes for Nadella's job, either literally, or as Microsoft does a 10-10-10 score swan dive on the NASDAQ, I'll be quietly hobby coding over at a repo that has sensible AI policies and more of a small coder spirit.

Cheers,
Crunchy.
